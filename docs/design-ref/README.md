# AAGAM — Design Reference Assets

This directory stores visual references for AAGAM dashboard layout and styling.

### Reference Specification
- **Subject**: Layout + mood reference only (e.g., Stakent / QClay-style Finance Management Dashboard).
- **Key Visual Elements Borrowed**:
  - Dark technical surface (`#0d1117`)
  - Fixed sidebar navigation
  - Modular card grid
  - KPI overview tiles across the top
- **Strict Boundary**: No financial or crypto semantics (tickers, buy/sell). All data displays strictly show meteorological and disaster-management parameters (mm/24h, °C, km/h, lead days).

### Action Required
Place your design screenshot (e.g. `dashboard-reference.png`) into this directory before starting Phase 5/7 frontend dashboard design.
